# 🌍 Climatect

## 📌 Sobre o projeto

**Qual é o nome do projeto?**

Climatect

**Qual problema relacionado às mudanças climáticas o projeto pretende abordar?**

Abordará sobre proteções em condições climáticas perigosas

**Por que você escolheu esse problema?**

Porque eu acho que é importe para as pessoas caso ela não saiba como se proteger

## 🎯 Objetivos

**Qual é o objetivo principal do projeto?**

Mostrar o clima em determinada região e caso tenha condições climáticas perigosas, falar quando acontecerá e como se proteger

**Como o projeto poderá ajudar?**

Pode ajudar em servidores de discord

## 💡 Solução proposta

**Como o programa funcionará?**

o usuário ou terá que enviar um comando ou o bot falará sozinho, estou decidindo, mas a princípio o bot mandará informações climáticas do local escolhido pelo usuário e caso tenha condições climáticas perigosas ele dará uma dica para se prevenir

**Quais serão as principais funcionalidades?**

- Manda a condição climática de um determinado local
- Caso tenha condições climáticas perigosas ele dará uma dica para se prevenir

**Qual será o diferencial do projeto?**

Avisar os usuários que ocorrerá condições climáticas perigosas para o mesmo se proteger
